使用帮助

选区模式

  1. 启动后端服务，等状态变绿
  2. 用套索 / 魔棒 / 快速选择圈住要清除的内容
  3. 点「清除选区内容」
  4. 结果作为新图层贴在最上方

涂抹蒙版模式

  1. 切换到「涂抹蒙版」选项卡
  2. 点「创建蒙版图层」，PS 自动新建 LaMa_Mask 图层
  3. 用画笔随意涂抹要清除的区域（颜色不限）
  4. 点「清除涂抹区域」，处理完蒙版图层自动隐藏

小技巧

  • 「边缘扩展」3~10 像素能消除残影
  • 涂抹模式支持软画笔，边缘自然
  • 不满意按 Ctrl+Z 撤销，原图不受影响
  • 大图处理慢正常，CPU 模式 4K 图约 30s
